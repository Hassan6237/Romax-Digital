 Apple Wallet

{{ 'Connected' if current_user.apple_wallet_ready else 'Not connected' }}
Where do I get these?
  1. Enrol in the Apple Developer Program and create a Pass Type ID under Certificates, Identifiers & Profiles.
  2. Generate a certificate for that Pass Type ID and export it, together with its private key, as cert.pem and key.pem (e.g. via Keychain Access → Export, then openssl pkcs12 -in cert.p12 -clcerts -nokeys -out cert.pem / -nocerts -out key.pem).
  3. Download Apple's WWDR intermediate certificate and convert it to wwdr.pem.
  4. Upload all three below, along with your Team ID and Pass Type Identifier.

Where do I get these?
  1. Sign up for the Google Wallet API in Google Cloud Console and note your Issuer ID from the Google Pay & Wallet Console.
  2. Create a service account, grant it access to your Wallet issuer account, and download its JSON key file.
  3. Upload the JSON key below along with your Issuer ID.
